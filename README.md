## Featured projects - Portfolio

### 🎬 WRAP - Film Production Management System
A web platform for managing film productions - organizing scripts, production planning and scheduling, teams, and assets.

- 🔭 Currently working on: **WRAP**
- Key features:
  - **Script editor** (editing/structuring scripts as a core workflow)
  - **Two user roles: Crew and Cast** (role-driven experience and permissions)
  - **Scheduling** (planning and coordinating production work)

The project is currently in active development. While some features are still in the "visionary" stage, the core architecture is designed to handle the dynamic nature of movie sets.

Can't wait to shout: “It’s a WRAP!”
