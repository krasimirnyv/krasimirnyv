## Featured projects - Portfolio

### 🎬 WRAP - Film Production Management System
A web platform for managing film productions, helping in every phase of development - organizing scripts, production planning and scheduling, teams, and assets.

Currently working on: **WRAP**
Key features:
  - **Two user roles: Crew and Cast** (role-driven experience and permissions)
  - **Script editor** (editing/structuring scripts as a core workflow)
  - **Scheduling** (planning and coordinating production work)

The project is currently in **active development**. While some features are still in the "visionary" stage, the core architecture is designed to handle the dynamic nature of movie sets.

Can't wait to shout: “It’s a WRAP!”

Repo: <a href="https://github.com/krasimirnyv/Wrap-FilmProductionManagementSystem-ASP.NET-Project">Check the WRAP project</a>

### 🐍 Snake Game with Custom DI Framework
Classic Snake in C#, built on top of a custom-made **Dependency Injection / IoC** framework.

Highlights of the project are the developed custom **Dependency Injection framework**, a clean **OOP** structure (interfaces, responsibilities, extensibility). Easy for testing and debugging. And last but not least, there is the option to locally save the highest score for each user.
